# Source profile for the IEEE 1815.2 models

`full.json` is the input of `src/interoperability/models/ieee1815_2/generate_models.py`. It is the IEEE 1815.2 test
tool's full profile (https://github.com/pnnl/ieee-std-1815-2-test-tool, `data/profiles/full.json`, generated by the
tool's `pics_validator` from `full.xlsx`), reconciled on 2026-10-24 from two versions of that file:

* the version regenerated upstream on 2026-09-21 (commit `aaea1b9`, "fix missing data in xlsx files"), which corrected
  scaling on shared points: the AO selected-curve X/Y points (AO257 to AO448) now carry maximum 100 and multiplier 1.0,
  and several selected-schedule AI points (AI3000 to AI3067) have corrected minimum, maximum, multiplier and sample
  values; and
* the initial-release version (commit `2c7fcc8`), whose curve templates hold 100 X/Y point pairs (AI333 to AI532) and
  whose schedule templates hold 100 entries (AI3012 to AI3411), as IEEE Std 1815.2-2025 defines them (6.1.3
  AI328-AI532, 6.1.4 AI3000-AI3411). The upstream regeneration truncated these to 4 points and 14 entries although
  `full.xlsx` still lists every row; see `plans_and_analysis/ieee1815_2_test_tool_issues.md`.

Construction: the 2026-09-21 file, with the tail of each truncated template list (`AI.curves[*].x_values`,
`y_values`; `AI.schedules[*].time_offsets`, `action_types`, `action_indexes`, `values`) appended verbatim from the
initial-release file. Every point shared by the two versions has the 2026-09-21 values; every point present only in
the initial release is unchanged from it. The point set equals the initial release's.

Regenerate with (from this directory's parent):

    python src/interoperability/models/ieee1815_2/generate_models.py

When upstream restores the full templates, replace this file with the upstream profile and delete the reconciliation
note above.
