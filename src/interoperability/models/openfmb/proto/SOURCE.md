# OpenFMB protobuf bindings (vendored)

Generated Python bindings for the OpenFMB Platform Specific Model v2.2, copied unchanged from the OpenFMB
Users Group `psm-protobuf-python` repository (workspace copy `openfmb/psm-protobuf-python`, commit
`873351f06524ada335f345dfffe98ba44979ddb7`, 2025-07-30). Licence: see `LICENSE` in this directory.

Layout is the original one: `uml_pb2.py` at the top and one `<module>/<module>_pb2.py` per OpenFMB module. The
files import each other by top-level name (`import uml_pb2`, `from commonmodule import commonmodule_pb2`), so
`interoperability.codecs.openfmb` puts this directory on `sys.path` and imports `<module>.<module>_pb2`. Do not
import them under any other module name: the descriptor pool rejects a second registration of the same file.

Runtime requirement: `protobuf>=6.31.1` (the files were generated by protoc 6.31.1; the 7.x runtime loads them).
Install with the service's `openfmb` extra. The pydantic models in the parent package are generated from these
same bindings by `generate_models.py` and need no protobuf at runtime.
